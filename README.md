# 🤖 ZERO AI Assistant

ZERO is a modern AI chatbot built with Python and Streamlit.  
It provides a clean ChatGPT-style interface where users can chat with an AI assistant, start new conversations, and select different personality modes.

## ✨ Features

- 🤖 AI-powered chatbot
- 💬 ChatGPT-style conversational interface
- 🆕 New Chat functionality
- 😊 Multiple personality modes
  - Happy
  - Sad
  - Angry
  - Professional
  - Funny
- ⚡ Fast and simple Streamlit UI
- 🌙 Modern dark-themed interface
- 📱 Responsive chatbot interface
- 🔌 API-based AI responses
- 🧠 Conversation-based interaction
- 🚀 Ready for deployment

## 🖥️ Interface

The ZERO chatbot includes:

- ZERO AI Assistant branding
- Online status
- Personality selector
- Current personality mode
- New Chat button
- User and AI message bubbles
- Chat input box
- Clean dark UI

## 🛠️ Technologies Used

## 📁 Project Structure


Zero_Chat/
│
├── app.py
├── Chatbot.py
├── requirements.txt
├── .gitignore
└── README.md

1. Clone the repository:- git clone https://github.com/Uttam15122005/Zero_Chat.git
2. 2. Open the project:- cd Zero_Chat
3. 3. Create a virtual environment :- python -m venv .venv (Windows PowerShell)
4. Activate the virtual environment:- .venv\Scripts\Activate (Windows PowerShell)
5. Install dependencies:- pip install -r requirements.txt (Windows PowerShell)
6. API Configuration:- API_KEY=your_api_key_here
7. ▶️ Run the Application = streamlit run app.py (Windows PowerShell)
   Then open the local URL shown in the terminal, usually:
   http://localhost:8501
8. 💬 Example Questions

You can ask ZERO questions such as:

What is Python?
Explain machine learning in simple terms.
Write a professional email asking for an internship.
Explain what an API is.
Write a Python program to reverse a string.
Give me a roadmap to become an AI Engineer.

9. 🎭 Personality Modes

ZERO supports different conversation personalities.

Mode	Description
😊 Happy	Friendly and positive responses
😢 Sad	Calm and emotional tone
😠 Angry	Strong and direct tone
💼 Professional	Formal and professional responses
😂 Funny	Humorous and entertaining responses
